## 학습 방식

책의 짧은 설명 → 저자 예제 이해 → 결과 예상 → 직접 실행 → 예제를 가린 적용 문제 → 다음 학습에서 회상합니다. 변수·자료형부터 시작해 자료구조·함수·NumPy·pandas로 이어갑니다. 단계는 이해 상태에 따라 조정합니다.

## 기록 기준

- 최초 시도와 오류를 최종 코드·수정 이유와 함께 남깁니다.
- 직접 작성 / 교재 예제 / AI 설명·힌트를 구분합니다.
- 사용자 제공 출력과 AI가 검증한 출력을 구분합니다.
- 수업 계획과 실제 학습 기록을 구분합니다.

ChatGPT/Codex가 설명, 예제 안내, 오류 피드백과 파일 정리를 도왔습니다. 원본 데이터와 개인 PC의 절대 경로는 공개하지 않습니다. Notion과 GitHub는 수업을 마칠 때 명시적으로 갱신하며, 자동 동기화나 예약 실행은 없습니다.
