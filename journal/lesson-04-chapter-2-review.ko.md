## 01. 목표

문자열을 정수로 바꿔 계산하고, 조건문으로 수량을 확인하고, 반복문으로 여러 수량의 총금액을 구했습니다.

---

## 02. 사용한 문법

`int()`로 문자열을 정수로 바꿉니다. `if`와 `else`로 수량에 따라 실행할 코드를 고릅니다. `for`는 리스트에서 값을 하나씩 꺼냅니다.

---

## 03. 직접 작성한 코드

### 1회차. 형 변환과 곱셈

```python
price_text = "35"  # 가격을 문자열로 저장합니다.
quantity_text = "6"  # 수량을 문자열로 저장합니다.

price_number = int(price_text)  # 가격 문자열을 정수로 바꿉니다.
quantity_number = int(quantity_text)  # 수량 문자열을 정수로 바꿉니다.

print(price_number)  # 변환한 가격을 출력합니다.
print(quantity_number)  # 변환한 수량을 출력합니다.

amount = price_number * quantity_number  # 정수 가격과 수량을 곱해 총금액을 저장합니다.
print(amount)  # 총금액을 출력합니다.
```

### 2회차. 조건문

```python
price = 35  # 가격을 35로 정합니다.
quantity = 0  # 수량이 0인 경우를 확인합니다.

if quantity <= 0:  # 수량이 0 이하인지 확인합니다.
    print("수량 확인 필요")  # 조건이 참이면 확인 메시지를 출력합니다.
else:  # 수량이 양수일 때 아래 코드를 실행합니다.
    amount = price * quantity  # 가격과 수량을 곱해 총금액을 저장합니다.
    print(amount)  # 총금액을 출력합니다.
```

### 3회차. 반복문

```python
price = 35  # 모든 계산에 같은 가격 35를 씁니다.
quantities = [2, 5, 8]  # 계산할 수량을 리스트로 모읍니다.

for quantity in quantities:  # 리스트에서 수량을 하나씩 꺼냅니다.
    amount = price * quantity  # 이번 수량에 가격을 곱합니다.
    print(amount)  # 반복할 때마다 총금액을 한 줄씩 출력합니다.
```

`quantity`를 `0`에서 `3`으로 바꿔 실행하면 2회차의 `else` 분기에서 `105`를 확인할 수 있습니다.

---

## 04. 실제 출력

- 1회차: `35`, `6`, `210`.
- 2회차: 수량 `3`에서 `105`, 수량 `0`에서 `수량 확인 필요`.
- 3회차: `70`, `175`, `280`이 한 줄씩 출력됐습니다.

---

## 05. 처음 시도와 수정

1회차에서는 변환한 가격과 수량을 먼저 출력하고, 안내 후 총금액 계산을 추가했습니다. 2회차에서는 조건의 대상을 가격에서 수량으로 바꾸고, `if`에는 확인 메시지, `else`에는 총금액 계산을 두었습니다. 3회차의 첫 식은 가격과 수량 리스트 전체를 곱했습니다. `for`에서 수량 하나씩 꺼내 곱하도록 바꿨습니다. 채팅에 붙여 넣은 코드와 달리 실제 저장본에서는 `print(amount)`가 반복문 안에 있었습니다.

---

## 06. 반복문 설명

가격 35는 그대로이고, quantities에서 꺼낸 값이 quantity에 2, 5, 8 순서로 들어갑니다. 반복문 안에서 매번 곱하고 출력해서 70, 175, 280이 한 줄씩 나옵니다.
