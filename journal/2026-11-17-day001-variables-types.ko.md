## 📖 02. 교재 예제

저자 예제의 a = 5 / type(a) / a = "foo" / type(a)를 .py에서 결과가 보이도록 print로 감싸 실행했습니다. 사용자는 int → str를 예상하고 출력과 비교했습니다. 마지막 print(a)는 foo라고 예상했고 실제 출력도 일치했습니다.

---

## ✍️ 03. 사용자 최종 코드

원래 문제는 숫자 → 문자열 순서였지만 사용자는 반대 순서로 작성했습니다. 순서는 달라도 코드와 출력은 맞습니다.

```python
value = "7"
print(type(value))

value = 7
print(type(value))

print(value)
print("value")
```

사용자는 마지막 두 출력이 각각 저장된 7과 글자 value라고 먼저 설명했습니다.

---

## 🖥️ 04. 사용자가 공유한 실제 출력

```text
<class 'str'>
<class 'int'>
7
value
```

출력 예측과 결과가 일치합니다. AI도 정리본을 별도로 실행해 같은 출력을 확인했습니다. 두 검증 주체를 구분합니다.

---

## 🛠️ 05. 최초 시도와 수정 이유

초기에는 7만 보이는 결과를 공유해 자료형을 확인할 수 없었습니다. 숫자 7과 문자열 "7"은 print 결과가 같아 type()이 필요하다는 힌트를 받았습니다. 이후 str만 또는 int만 출력된 기록을 거쳐, 두 대입·출력을 한 파일에 함께 작성했습니다. 실제 예외 메시지는 공유되지 않았으므로 임의의 오류를 추가하지 않았습니다.

---

## 🧠 06. 이해 확인과 도움받은 부분

- 문자열과 정수의 자료형을 코드로 확인했습니다.
- print(value)와 print("value")의 차이를 설명했습니다.
- 교재 예제, AI 개념 설명, print(type(value)) 힌트를 참고했습니다.
