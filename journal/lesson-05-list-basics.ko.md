# 수업 05 — 교재 3장 리스트 기초

[English](lesson-05-list-basics.en.md) · [수업 코드](../lessons/ch03/lesson_05_ch03_lists.py) · [Notion](https://app.notion.com/p/41c058a09a5b81e599f1dc252c3ee924)

## 01. 목표

여러 건의 수량을 리스트에 담고, 값 하나를 추가한 뒤 각각의 총금액을 계산했습니다.

---

## 02. 사용한 문법

리스트의 위치 번호는 `0`부터 시작합니다. `append()`는 맨 끝에 값을 추가하고, `for`는 리스트에서 값을 하나씩 꺼냅니다.

---

## 03. 직접 작성한 코드

세 코드 블록은 같은 리스트를 사용하므로 순서대로 실행합니다.

### 1. 위치로 값 꺼내기

```python
quantities = [2, 5, 8]  # 세 건의 수량을 리스트 하나에 저장합니다.
print(quantities[1])  # 위치 번호 1에 있는 두 번째 값을 출력합니다.
```

### 2. 리스트에 값 추가하기

```python
quantities.append(3)  # 리스트 끝에 수량 3을 추가합니다.
print(quantities)  # 추가한 값까지 포함된 리스트를 출력합니다.
```

### 3. 반복문으로 총금액 계산하기

```python
price = 35  # 모든 수량에 적용할 가격을 정합니다.
for quantity in quantities:  # 리스트에서 수량을 하나씩 꺼냅니다.
    amount = price * quantity  # 이번 수량에 가격을 곱합니다.
    print(amount)  # 이번 총금액을 한 줄에 출력합니다.
```

---

## 04. 실제 출력

민섭님이 공유한 실행에서는 2~3번 결과가 아래처럼 나왔습니다. 그 실행에서는 1번 출력문이 주석 처리되어 있었습니다. 저장된 파일에서는 리스트를 만든 직후 1번 출력문을 실행하므로, 정리본을 실행했을 때 첫 줄에 `5`가 추가되는 것도 확인했습니다.

```text
[2, 5, 8, 3]
70
175
280
105
```

---

## 05. 실행 순서

저장된 코드에서는 리스트를 만든 바로 다음 줄에 `print(quantities[1])`을 두고, 그다음 `append(3)`을 실행합니다.

---

## 06. 반복문 설명

`3`을 추가한 뒤 `for`가 `2`, `5`, `8`, `3` 순서로 수량을 꺼냅니다. 가격은 `35`로 고정되어 있고, 반복할 때마다 `quantity`에 들어가는 값이 바뀝니다.

---
