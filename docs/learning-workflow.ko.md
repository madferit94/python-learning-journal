# 교재 학습과 일일 마무리

[English](learning-workflow.en.md)

## 수업 시작

오늘의 파일과 가장 최근 TIL을 읽고, 미완료·복습 필요 항목부터 확인합니다. 날짜가 지났다고 다음 수업을 완료 처리하거나 새 진도를 자동으로 추가하지 않습니다.

## 수업 진행

새 개념은 설명과 짧은 예제를 제공합니다. 직접 풀 문제는 빈 공간으로 남기고 사용자가 먼저 작성합니다. 오류에는 원인·힌트를 우선 제공하며 필요할 때 수정 코드를 설명합니다. 설명을 이해했는지 사용자가 본인 말로 표현하도록 확인합니다.

## 수업 종료

1. 저장된 코드, 대화와 실제 출력부터 확인합니다.
2. Python 파일을 개념·예제·사용자 코드·출력·오류·피드백·다음 복습으로 정리합니다.
3. 최초 시도와 카테고리를 보존합니다. 중복은 설명 후 정리하되 학습 이력을 삭제하지 않습니다.
4. 필요한 문법·예제 실행만 검증하고, AI 실행은 사용자 실행으로 기록하지 않습니다.
5. 지정된 Notion 학습 기록을 먼저 읽고 갱신합니다. 학습일·예정일 속성이나 본문 날짜 안내는 넣지 않습니다.
6. 공개용 코드 설명과 당일 TIL을 한국어·영어 두 버전으로 이 GitHub에 반영합니다. 비공개 데이터·PC 절대 경로는 제외합니다.
7. 양쪽 링크와 미해결 복습 문제를 공유합니다. 사용자는 장문의 회고를 별도로 복사할 필요가 없습니다.

GitHub를 원본 교재 저장소로 쓰거나 수집한 CSV를 무조건 재배포하지 않습니다. Notion과 GitHub는 자동 연동이 아니며 실제 수업 대화가 있는 날 마무리 작업으로 갱신합니다.

## 읽기 쉬운 화면 기준

Notion의 일일 TIL은 상단 요약 콜아웃, 번호 있는 큰 제목, 구분선, 긴 코드·오류를 담은 토글을 사용합니다. 목표·교재 예제·사용자 코드·실제 출력·오류 수정·이해 확인·복습을 시각적으로 분리합니다. 교재 예제와 실제 풀이·AI 검증 결과를 같은 블록에 섞지 않습니다. 미실행·미확인 상태는 색상뿐 아니라 글자로 명시합니다. GitHub는 동일한 구획을 일반 Markdown으로 표현합니다.

Notion 상단에는 GitHub 한국어·English 링크를 둡니다. 본문은 01~07 구획으로 정리하고 08 자료·코드 구역, 로컬 경로, 파일 예정일 안내는 넣지 않습니다.
