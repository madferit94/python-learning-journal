# Book study and session closing

[한국어](learning-workflow.ko.md)

## Start

Read the current lesson and latest journal. Check unresolved questions and recall tasks first. The passage of time does not complete a lesson or justify automatically advancing the topic.

## Study

Explain new syntax using a short example. Leave application exercises blank for the learner to attempt first. Respond to mistakes with causes and hints before supplying corrections where needed. Ask the learner to explain the concept in their own words.

## Close

1. Read the saved code, conversation and actual output.
2. Organize the Python file into purpose, concepts, examples, learner code, output, corrections and recall.
3. Preserve initial attempts and learning categories; remove duplication without erasing the learning trace.
4. Verify relevant syntax and examples. Never relabel agent execution as learner execution.
5. Read and update the designated Notion record. Do not add study-date or planned-date fields or date explanations to its body.
6. Publish public-safe code explanations and journals in Korean and English. Exclude private data and absolute local paths.
7. Share links and the remaining recall task; the learner need not copy a long retrospective manually.

Keep textbook notebooks and raw datasets out of this journal. Updates happen explicitly during session closing; there is no automatic or unattended synchronization. Finishing a session is separate from independent recall.

## Readability

Use a Notion summary callout, numbered headings, separators, and toggles for long examples or error traces. Separate goals, textbook examples, learner code, actual outputs, corrections, understanding and recall. State unverified status in words as well as color. GitHub uses equivalent Markdown sections.

Put Korean and English GitHub links near the top of Notion. Use sections 01–07. Omit a section 08 resource footer, local paths and filename/schedule explanations. Each public lesson, journal, workflow and template has a language counterpart linked at the top.
